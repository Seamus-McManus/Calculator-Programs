# DVD Logo Screensaver!
A little animation programmed in TI-89 Basic. It is based on the boucing DVD logo animation often found on old DVD players, and the little logo even changes "color" when it hits an edge. If you're patient enough, it will hit the corner!
<br>
### How to set it up:
1. Download all the bitmap images and the program file **DO NOT RENAME THE IMAGES** 
2. Send them to you calculator using the correct *TI-Connect* program (make sure it is compatible with TI-89)
### How to use the program:
- To execute the program, confirm that all the images are in the **main** file path 
- Just type in the newsvr() command into the calculator and the program will execute
- To exit the program, press any button
- If your calculator falls asleep and you want to continue watching the "screensaver", just press the on button and the program should still work
