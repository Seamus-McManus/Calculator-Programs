# Parallel Line Calculator
A simple program I made that solves a very specific and annoying type of problem that I kept getting in math class a long time ago XD
## How to Set it Up:
-Just put the calcpll.8xp file on your TI-89 in any directory using the *TI-Connect* compatible with your TI-89 calculator
## How to use:
To explain this, I am going to use an example math problem where you can use the program: 
>"Find the equation of a line parallel to y=3x+4 that passes through the point (2, 1)"
1. **Start the program**. Just type calcpll() into your TI-89's home menu.
2. **First you need to find the slope** (I am sorry, in this version you do need to use some brain power). Since the equation is in y = mx+b form, **the slope (m) is 3**. Type that into the *Slope* field of the program
3. **Get the X and Y Coordinates**. In this case X is 2 and Y is 1. Type those into the X and Y fields respectively.
4. Type enter, and you should get your answer!

## Tips/Tricks
- If you for some reason want to find a perpendicular line, type the negative and opposite version of the original equation's slope (using the last example, you would instead enter the slope -1/3 into the program)
- If you are super lazy, you can probably use the builtin solve function to solve for the slope with some finagling.
